# Mon projet

## PMODALS

### Description 
    Le module PMODALS permet la lecture de données provenant de capteurs analogiques. Il est essentiel de noter que ce module doit être branché au port JA de la Raspberry Pi pour fonctionner correctement. Ce port permet la communication entre le module PMODALS et la Raspberry Pi via les connexions appropriées.
### Fonctionnalités 
    Lecture de valeurs analogiques, conversion en numérique pour traitement et affichage.
